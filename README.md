# سامانه مدیریت پرسنل، پیمانکار و انبار (Personnel CRM)

سیستم سازمانی راست‌چین با تم مدرن و سبک روشن برای مدیریت نیروهای داخلی و پیمانکار، حضور و غیاب ساعتی، تحویلات انبار و گزارش‌های روزانه پروژه‌ها. کاملاً فارسی با فونت وزیرمتن، اعداد فارسی و تقویم شمسی.

## معماری

- **بک‌اند:** Cloudflare Worker (javaScript استاندارد Web APIs، بدون وابستگی خارجی)
- **دیتابیس:** Cloudflare D1 (SQLite) — شِما در اولین اجرا خودکار ساخته می‌شود
- **فرانت‌اند:** HTML/CSS/JS استاتیک سرو‌شده به‌صورت ASSET از همان Worker
- **احراز هویت:** نشست امضاشده با HMAC (کوکی HttpOnly) + رمز عبور با PBKDF2-120k
- **نقش‌ها:** مدیر کل / مدیر / اپراتور ثبت / مشاهده‌گر

## امکانات

- تعریف پروژه‌ها و ارتباط هر پروژه با پیمانکاران مرتبط
- تعریف پیمانکاران و پرسنل (داخلی یا نیروی پیمانکار) با کد پرسنلی یکتا
- حضور و غیاب روزانه گروهی به‌تفکیک پروژه و پیمانکار با ساعت ورود/خروج و محاسبه کارکرد
- ثبت تحویل اقلام انبار به پرسنل داخلی یا نیروی پیمانکار، با تاریخ شمسی
- گزارش روزانه هر پروژه (یک رکورد در روز، قابل ویرایش)
- خروجی CSV سازگار با اکسل برای حضور و غیاب، تحویلات و گزارش‌ها
- داشبورد عوارضی (پروژه فعال، حاضران امروز، تحویل امروز و ...)
- داشبورد سطح دسترسی چندسطحی برای چند مدیر با دسترسی‌های متفاوت

## اجرای محلی

```bash
npm install
npm run assemble   # بازسازی worker.js و فایل‌های public از قطعه‌ها
npm run dev        # http://localhost:8787
```

ورود اولیه: نام کاربری `admin` و رمز `Admin@2026` (بعد از ورود، از بخش «مدیران و دسترسی‌ها» رمز را تغییر دهید).

## استقرار روی Cloudflare

دیتابیس D1 را بسازید و به کارگر با نام binding `DB` وصل کنید؛ فایل‌های استاتیک از پوشه `public` با binding `ASSETS` سرو می‌شود.

```bash
npx wrangler d1 create personnel-crm
npx wrangler d1 execute personnel-crm --remote --file=schema.sql
npx wrangler deploy
```

نکته: دیتابیس در اولین درخواست نیز خود‌کار مقداردهی می‌شود؛ اجرای `d1 execute` صرفاً سرعت راه‌اندازی را بالا می‌برد.

## فونت وزیرمتن

نسخه woff2 در مسیر `public/fonts` قرار دارد. در صورت نیاز به دریافت مجدد (برای مثال کست تمیز از مخزن):

```bash
node scripts/fetch-fonts.mjs
```

## بازسازی فایل‌های اصلی از قطعه‌ها

فایل‌های `worker.js`، `public/css/styles.css` و `public/js/app.js` به‌دلیل محدودیت اندازه در API گیت‌هاب، به‌صورت قطعه‌قطعه در پوشه `parts/` ذخیره شده‌اند. برای ساخت فایل‌های اصلی:

```bash
npm run assemble
```
